Pretend Product 1 page

This page shows how any Product 1 web app can embed the Scholarship Discovery Companion. Click the blue 🎓 Find scholarships button in the bottom-right corner.

Option A – floating button (one line)

<script src="__BASE__/companion/embed.js" defer></script>

Option B – inline iframe

<iframe src="__BASE__/companion" style="width:380px;height:600px;border:0"></iframe>

Option C – pre-filled for a known student

Your server calls POST /v1/chat/sessions with your X-API-Key and external_ref, then puts the returned companion_url in an iframe (or passes data-session/data-token to embed.js). Never put the API key in browser code.
